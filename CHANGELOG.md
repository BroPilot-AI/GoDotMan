# Changelog

All notable changes to this project will be documented in this file.

## [1.0] - 2026-11-02

### Added
- Initial project setup with Godot 4.x
- Main menu scene with character selection (Gobot, GDBot, Sophia)
- Multiple world scenes (world_1.tscn through world_10.tscn)
- Character scenes (player.tscn, bee_enemy.tscn, bat_enemy.tscn, etc.)
- HUD (heads-up display) scene
- Various power-up and projectile scenes
- Game manager autoload script
- Main menu script
- Character avatars and sprites
- Input mappings for keyboard and gamepad
- Jolt Physics integration in project settings
- Basic game assets and configurations
